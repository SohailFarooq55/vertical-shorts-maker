# Spotlight effect — example captions

Captions from a real 10-second Short: "Nobody Is Watching You" — the spotlight effect.

Voiceover text (25 words):

> Nobody watches you as much as you think. It's called the spotlight effect. Everyone is too busy worrying about themselves. So stop waiting. Start now.

The JSON in `captions.json` has no timings on purpose — `shorts_maker.py` splits the time by word count, scaled to your measured voiceover length.

Run it with the demo assets from the main README, or with your own 3 images + voiceover.
